# AetherLearn AI — User Research Template

> **Important:** This document contains interview and survey questions for collecting real student feedback. No responses have been fabricated. All response fields are blank and ready for actual data collection.

---

## Purpose

This template is used to validate that the AetherLearn AI platform addresses real daily problems faced by students learning programming. It follows the Project Better Tomorrow **Pathway B — Fresh Discovery Track** approach of understanding user friction before designing solutions.

---

## Target Participant Profile

Participants should meet at least one of these criteria:

- Currently enrolled in a programming course (CS, IT, Data Science, etc.)
- Self-taught programmer in the beginner-to-intermediate stage
- Student preparing for coding assessments or technical interviews
- Anyone who has struggled to learn programming independently
